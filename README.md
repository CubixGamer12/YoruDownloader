<h1>Features</h1>
</div>

- **High Quality Media**: Support for 4K video and high-bitrate audio (MP3, FLAC, Opus).
- **Format Support**: Download in MP4, WebM, MKV, MP3, M4A, and more.
- **SponsorBlock**: Automatically remove sponsored segments, intros, and outros.
- **Smart Metadata**: Embed thumbnails, descriptions, and full metadata into files.
- **Advanced Subtitles**: Download and embed subtitles in multiple formats.
- **Cookie Support**: Support for cookies.txt to access age-restricted or private content.
- **Speed Optimization**: Concurrent fragment downloading for maximum throughput.
- **Codec Selection**: Preference settings for H.264, VP9, or AV1 codecs.
- **System Integration**: Integrated with the Android system share menu.
- **Network Control**: Wi-Fi Only mode to save cellular data.
- **Custom Storage**: Flexible download path selection, including SD cards.
- **UI & UX**: Modern Material 3 interface with Dynamic Color support.

<div align="center">
<h1>Technical Stack</h1>
</div>

- **Jetpack Compose**: Modern declarative UI framework.
- **Material 3**: Latest design system from Google.
- **yt-dlp**: Industry-standard command-line media downloader.
- **FFmpeg**: Framework for media processing and muxing.
- **Kotlin Coroutines**: Structured concurrency for background tasks.
- **Coil**: Image loading for thumbnails.

<h1>Development Setup</h1>
</div>

1. Clone the repository.
2. Open the project in Android Studio (Ladybug or newer).
3. Ensure JDK 17 is configured.
4. Build the project using Gradle.

```bash
./gradlew assembleDebug
```
